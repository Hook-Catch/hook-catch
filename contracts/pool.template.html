Listing pool

Creates a small ETH / token pool on Uniswap v4 at the token's current Pons price, so DexScreener lists the token before graduation. The Pons graduation pool is a different pool (fee 0, Pons hook) and is not affected.

1. Allow Permit2 to move the token —

Standard Uniswap approval, once per token.

2. Allow the position manager —

Lets Uniswap's position manager take exactly the tokens shown above, valid for one day.

3. Create the pool and add liquidity —

One transaction: starts the pool at the Pons price and deposits both sides over the full price range. Unused ETH comes back.

4. Lock it forever (optional) —

Sends the position NFT to 0x…dEaD, so nobody can ever remove this liquidity. Proof against "rug" questions.
